# knowledge

Wild Rift の静的知識（チャンピオン / アイテム / ルーン / パッチ）を提供する Bounded Context。

## 責務

- 自作の MCP サーバーからチャンピオン / アイテム / パッチ情報を取得する
- MCP クライアントをこのモジュール内に閉じ込め、他モジュールには公開 API だけを見せる
- **MCP が落ちてもコーチングは（精度を落として）成立させる。必須依存にしない**
